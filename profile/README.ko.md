ThreeLight Studio는 AI 시대를 위한 실용적인 도구, 인터페이스, 워크플로를 탐구하는 작은 제품 스튜디오입니다.

## 라이브 제품

| 제품 | 설명 |
| --- | --- |
| [MapBridge](https://mapbridge.threelight-studio.com/) | ThreeLight Studio의 지도 기반 인터페이스 실험입니다. |

## 주요 오픈소스

| 프로젝트 | 설명 |
| --- | --- |
| [Rendium Desktop Studio](https://github.com/ThreeLightStudio/rendium-workspace) | 창작 작업을 위한 완전 로컬·로그인 없는 무료 비디오 편집기입니다. |
| [What Was I Searching For?](https://github.com/ThreeLightStudio/what-was-i-searching-for) | 검색 탭을 열고 왜 열었는지 바로 잊어버리는 순간을 위한 작은 인터넷 분실물 보관소입니다. |
| [PolyHarness](https://github.com/ThreeLightStudio/polyharness) | 한국어 입력을 영어 프롬프트로 변환해 토큰 효율을 실험하는 프록시 프로젝트입니다. |
