# ThreeLight Studio

Open-source products and small experiments for AI-native workflows, local-first tools, and creative software.

[한국어 README](https://github.com/ThreeLightStudio/ThreeLightStudio/blob/main/README.ko.md) · [Website](https://threelight-studio.com/) · [Personal profile](https://github.com/ThreeLight2000)

ThreeLight Studio is a small product studio exploring practical tools, interfaces, and workflows for the AI era.

## Featured projects

### [Rendium Desktop Studio](https://github.com/ThreeLightStudio/rendium-workspace)

A free, fully local, no-login video editor for creative workflows.

### [What Was I Searching For?](https://github.com/ThreeLightStudio/what-was-i-searching-for)

A tiny internet lost-and-found for the moment you open a search tab and forget why you came.

### [PolyHarness](https://github.com/ThreeLightStudio/polyharness)

An experimental proxy for testing Korean-to-English prompt translation and token efficiency.
